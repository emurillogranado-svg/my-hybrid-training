GUÍA DE SUSTITUCIONES

Si no puedes hacer un ejercicio por falta de material o nivel, usa estos cambios:

TRACCIÓN (PULL)
Pull-ups ➔ Ring Rows / Remo con mancuerna
Muscle Ups ➔ Pull-up pesado + Fondo
EMPUJE (PUSH)
Handstand Push-ups ➔ Press de hombro con mancuerna
Bench Press ➔ Flexiones con peso (Weighted Push-ups)
HALTEROFILIA
Power Clean ➔ KB Swing / Clean con mancuernas
Thrusters ➔ Wall Balls / Goblet Squat
CARDIO
Run 400m ➔ 500m Row / 1200m Bici / 2 min Comba
Double Unders ➔ 2x Single Unders (Saltos simples)
REGLA DE ORO: Si cambias un ejercicio, busca que trabaje el mismo músculo. Si es un ejercicio de saltar y no puedes, busca otro ejercicio explosivo de piernas.
